# Sun Panel 优化目标

本文记录已确认的后续优化方向。除正在讨论的 OAuth 身份模型外，其余项目按优先级逐步实施。

## 已排除

- 密码哈希算法暂不调整。
- 配置与密钥管理暂不纳入本轮目标。

## 优化目标

### 1. OAuth 身份模型（当前讨论）

- 使用 OIDC `sub` 作为稳定的外部身份关联键。
- 邮箱只作为账号展示和联系字段，不作为唯一身份键。
- 支持用户邮箱变更后仍关联到原有本地账号。
- 兼容多个 OAuth 提供商，关联键至少包含 `provider + sub`。
- 避免将邮箱或 `sub` 自动写入 `publiccode`。
- 处理历史上已经按邮箱或 `sub` 创建的账号，避免重复账号。

### 2. 前端路由与静态资源

- 统一处理 Vue history 路由回退。
- 保证 `/api/*` 仍返回 JSON 错误，不被 SPA fallback 截获。
- 登录回调 URL 中的 token 使用后及时清理，避免长期出现在地址栏和历史记录。
- 拆分过大的前端 chunk，改善首屏加载。

### 3. 用户创建与数据库一致性

- 用户创建和默认分组创建放入同一事务。
- 重新设计 `publiccode` 的可空/唯一约束。
- 为 OAuth 重复登录、邮箱变更和并发首次登录增加测试。

### 4. JWT 与会话

- 增加 issuer、audience 和更严格的 secret 校验。
- 评估短时 access token + refresh token 模式。
- 保留并完善 token version 的注销和批量失效能力。

### 5. 服务运行与部署

- 提供 systemd/runit 或 Compose 的正式服务定义。
- 增加健康检查、自动重启和优雅停止。
- 统一日志输出和轮转策略。

### 6. 后端架构

- 减少 `global` 和包级可变状态。
- 通过依赖注入传递配置、数据库和业务服务。
- 保持 router、service、repository、infra 的职责边界。

### 7. 测试与交付

- 为 OAuth、用户创建、JWT 撤销和路由回退补充回归测试。
- 在 CI 中执行 Go 测试、前端类型检查和生产构建。
- 发布时生成可追踪的版本号和构建信息。
